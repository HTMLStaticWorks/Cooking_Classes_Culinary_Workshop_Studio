# Culinara Culinary Studio & Workshop - Static Website

This project is a 100% static website built with **HTML5**, **Vanilla CSS**, and **Vanilla JavaScript**.

## 🌐 Final 9 Static HTML Pages

1. [`index.html`](index.html) — Home 1 (Warm Kitchen Theme) — *Mandatory*
2. [`home-2.html`](home-2.html) — Home 2 (Chef's Table Dark + Michelin Teaser) — *Mandatory*
3. [`about.html`](about.html) — About Our Studio & Heritage Kitchens — *Mandatory*
4. [`services.html`](services.html) — Workshops Catalog, Curriculum Breakdowns & Passes/Pricing — *Mandatory*
5. [`contact.html`](contact.html) — Studio Location, Hours & Concierge Form — *Mandatory*
6. [`gallery.html`](gallery.html) — Kitchen, Workstations & Food Gallery
7. [`blog.html`](blog.html) — Culinary Journal & Recipe Science
8. [`blog-details.html`](blog-details.html) — Journal Article & Recipe Note Callout
9. [`404.html`](404.html) — Recipe Not Found Fallback Page

## 📁 Assets Directory

- `assets/css/style.css` — Compiled Tailwind CSS stylesheet
- `assets/css/dark-mode.css` — Dark mode theme overrides
- `assets/css/rtl.css` — Right-to-left layout overrides
- `assets/js/main.js` — Global interactivity, theme toggle, modals & toasts

## 🚀 How to Run

Simply open `index.html` in any web browser or serve with any static web server (e.g. Live Server, Nginx, Apache, GitHub Pages, Vercel, Netlify). No Node.js build step required.
